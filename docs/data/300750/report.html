宁德时代（300750）2019-2022 超级成长股复盘报告

视角模式：both（当时视角 + 事后视角） · 数据区间：2019-01-01 ~ 2022-12-31（行情延伸至 2023-04-28） · 生成方式：ReviewGrowth 系统（官方源+双源核验，全部结论附来源）
本文以「当期财报 + 当期研报」的 as-of 视角为主线，所有判断均可从巨潮公告、原始研报 PDF、财务数据追溯。仅供学习研究，不构成投资建议。

一、总览

一句话结论：宁德时代 2019-2022 走完了「业绩领先认知 → 认知确认 → 戴维斯双击 → 成本冲击压力测试 → 盈利修复但估值中枢下移」的完整超级成长周期。六个核心假设中五个被增强或修复，唯一被真正破坏的是「高估值可维持」假设（H6）——这决定了 2022 年「业绩创新高、股价下跌 43%」的背离。

四层证据链：

  • 产业层：国内新能源车渗透率从约 5%（2019）升至约 27%（2022）；全球动力电池需求同期增长约 5 倍；储能市场 2021-2022 从 0 到 1 爆发。赛道处于 S 曲线最陡段。
  • 公司层：单季营收三年 11.8 倍（99.8 → 1,182.5 亿）；国内份额 50%+、全球份额 28% → 35.5%（SNE 口径，2022-10 电话会引用）；储能 + 技术授权（ATL 年 1.5 亿美元×10 年）第二曲线成形。
  • 预期层：卖方框架经历完整循环——50x PE（2019-04，目标价 102 元）→ 100x PE（2021-04，450 元）→ 80x PE（2021-10，825 元）→ 58x（2022-05）→ 40x（2022-08）→ 37x（2023-03）；盈利预测则近乎单向以上修为主（2022-05 与 2023-03 两次下修为仅有的收缩）。
  • 交易层：潜伏期横盘偏弱（2019 全年 +44.5%，几乎全部由 11-12 月贡献），确认期 +186.8%，主升期 +249.3%——自 2019 年初至 2021-12-03 顶部累计约 9.4 倍；2022 年最大回撤约 -49%（收盘口径 -46%）；2022-08-24 中报大幅超预期后股价滞涨——背离进入常态化。

最早信号 / 破坏信号 / 验证信号（详见第七节逻辑验证）：

  • 最早信号（2019-04-27）：2019Q1 财报「营收 +168.9% + 经营现金流 49.8 亿」发布当日股价下跌——业绩与认知背离的起点；
  • 修复信号（2022-05-04）：Q1 电话会管理层给出「调价落地、Q2 逐步实施」的可验证指引；
  • 破坏信号：从未出现在分子端；唯一破坏发生在估值假设（H6）——2022 年盈利创新高过程中定价锚从赛道溢价切换到盈利质量。

阶段要点：

  1. 潜伏期（2019）：基本面的「数据链」已经完整（收入高增、份额提升、现金流强劲、减值计提保守），但叙事被「补贴退坡」主导。2019Q2/Q3 两份财报中，收入增速换挡但毛利率逆势、减值一次性——所有恶化项均有结构化解释。此阶段 as-of 识别的关键不是预测政策，而是观察「以量补价是否成立」。
  2. 确认期（2019-11 ~ 2020-07）：三个确认信号依次落地——月线转强（2019-11，领先）、特斯拉合作公告（2020-02-03）、197 亿定增落地（2020-07-17，发行价 161 元，高瓴/本田等参与）。期间疫情冲击（2020-03，最低 53.8）被市场正确定性为一次性。
  3. 主升期（2020-07 ~ 2021-12）：连续超预期 + 两次盈利上修 + 估值扩张（PE 从约 110x 至 150x）。两次中等级别回撤（2021-02 抱团杀估值、2021-08 定增摊薄担忧）在 as-of 框架下均无基本面证据支撑——事后分别修复 +45% 与 +46%。
  4. 高位震荡（2021-12 ~ 2022-04）：顶点 352.5（2021-12-03，PE 130x+/PEG 1.1+）后，宏观（美联储/地缘）+ 成本（碳酸锂 50 万元/吨）+ 增速二阶导担忧共振；2022-02-11 放量跌破关键位；2022-04-25 罕见推迟披露一季报加剧恐慌；4-27~5-05 见底 181（自顶部 -49%）。
  5. 证伪期未破坏（2022-05 ~ 2022-12）：市场一度按「逻辑破坏」定价，但三个季度完成修复（归母 66.8 → 94.2 → 131.4 亿，毛利率 14.5% → 21.8% → 22.6%），450 亿定增在至暗时刻完成发行（发行价 410 元）。修复真实、但估值不回来——这正是本案例最有价值的一课。

  • 潜伏期：强财报后 T+20 为负（2019Q1 -12.5%、2019Q2 -0.1%）——市场明确不相信；唯一例外是 2019Q3（T+20 +18.0%、T+60 +71.8%）：拐点比「特斯拉公告」早一个季度在价格上出现。
  • 确认期:特斯拉公告（2020-02-03）T+5 +22.1%（随后被疫情回撤吞没，T+20 +3.4%）；疫情低点后修复强劲（2019Q4 财报 T+60 +43.1%）；197 亿定增落地（2020-07-17）T+60 +17.2%（相对创业板指 +16.2pct）。
  • 主升期：E 类事件 T+20 全部正收益（2020Q3 +2.5%→T+60 +62.9%、2020Q4 +18.3%、2021Q1 +9.4%、2021Q3 +7.7%）；2021-08-13 定增噪音 T+20 +0.0%、T+60 +22.5%——噪音与逻辑事件被清晰区分。
  • 压力期：2022-04-22 年报（最强数据）T+1 -6.1%、T+20 -3.9%——市场对「过去」不再买单；2022-04-30 Q1 崩坏后 T+5 +7.3%（利空出尽）。
  • 修复期：2022-05-04 电话会（含研报同声）T+20 +16.2%、T+60 +35.3%（相对创业板指 +18.6pct）——指引被抢跑；2022-08-24 中报 T+20 -20.8%、T+60 -28.0%（业绩与股价彻底脱钩）；2022-10-22 三季报 T+20 -5.4%。

八、复盘结论

做对了什么：

  1. 「数据领先认知」的识别——2019 年四份财报的现金流/份额数据完整支持基本面判断，等待认知修复需要耐心而非新信息；
  2. 「指引先于数据」的方法论——2022-05-04 电话会的可验证指引是全年最有效的决策锚点；
  3. 用超额收益区分下跌性质——2021-08 回撤（基本面向上）与 2022-03 下跌（基本面走弱）性质不同，前者加仓、后者减仓。

做错了什么 / 会做错什么：

  1. 高位依赖财报验证估值——2021Q4 的最强数据（+267%）恰在顶部区间，财报对「估值可维持」假设无检验力；
  2. 把「成本冲击」与「逻辑破坏」混淆的倾向——市场在 2022-04 按破坏定价，理性框架需要「价格传导机制存在与否」的二值判据。

噪音识别清单：减持公告、抱团股共振、定增预案情绪冲击、推迟披露的程序性恐慌——全部具备「与经营无关 + 可被结构化解释」的特征。

买卖点（按 as-of 规则而非事后价格）：

  • 买点：①2019-11 月线转强+连续两季数据兑现；②2020-03 疫情期间一次性定价；③2020-08 盈利转正+弹药落地；④2022-05 指引修复信号；⑤2022-10 地量+盈利兑现+PE 历史低位（事后看估值锚已变，需配合新叙事确认）。
  • 卖点：①2021-12 区域——PE 130x+/PEG 1.1+ 且「预期极值（825 元目标价）」出现；②2022-02-11 技术破位+成本压力公开化共振；③2022-08-24 业绩超预期后的滞涨（第二次背离警告）。

五条教训：

  1. 超级成长股的核心矛盾往往不是「增长是否真实」而是「估值假设能否维持」——六假设中唯估值假设永久破坏；
  2. 成本冲击是压力测试而非证伪：判据是「价格传导机制是否存在」；
  3. 龙头公司在拐点处的管理层指引，信息密度高于财报数字本身；
  4. 融资事件（定增）对股价的负面是脉冲式的，「发行完成」反而是确认信号；
  5. 复盘必须区分分母（估值/风格）与分子（盈利）——2022 年分子完好，分母崩塌，决定了所有「便宜」判断的失效边界。
